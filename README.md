 #    🎮 heroVsBoss | Portfolio & Character Showcase
heroVsBoss es una plataforma web desarrollada como proyecto personal para presentar el roster de personajes de mi próximo videojuego. Este espacio funciona como una galería interactiva donde los visitantes pueden explorar las habilidades, el trasfondo narrativo y la estética visual de cada héroe y jefe del juego.

###   🚀 Acerca del Proyecto
Este proyecto nació con el objetivo de consolidar el diseño de personajes y la programación frontend en una sola experiencia fluida. La web destaca por su sistema de animaciones personalizadas a 30 FPS y una interfaz inmersiva optimizada para el navegador.

 ###   🎨 Filosofía Creativa
Diseño de Personajes: Cada entidad presentada es un diseño original, conceptualizado con el apoyo de herramientas de Inteligencia Artificial para iteración rápida y refinamiento de estilo.

Animación: La ejecución técnica y el acabado final de las animaciones son 100% fruto de mi trabajo, asegurando que cada movimiento refleje la personalidad y el lore del personaje.

Desarrollo Frontend: Construido con un enfoque en rendimiento, utilizando Vanilla JavaScript (sin librerías pesadas) para manejar el pre-cargado de assets y la gestión de sprites en tiempo real.

🛠 Tecnologías Utilizadas
Frontend: HTML5, CSS3, Vanilla JavaScript.

Assets: Renderizado de sprites personalizados.

Optimización: Sistema de pre-cargado asíncrono para assets pesados y gestión de FPS mediante requestAnimationFrame.

Despliegue: https://anthodobleaa.github.io/HeroVsBoss/.
